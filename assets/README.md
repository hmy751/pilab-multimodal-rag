# 샘플 에셋

엣지 케이스를 재현하고 테스트하기 위한 **샘플 데이터** 영역입니다.

> **공개용 안내**: 실험에 쓰던 샘플 원본(영상·문서)은 제3자 저작물이라 공개 레포에서 제외했습니다.
> 현재 남아 있는 것은 질문셋 형식의 참고 자료뿐이며, 직접 확보한 데이터로 같은 흐름을 재현할 수 있습니다.

| 파일 | 설명 |
|------|------|
| [`track-b/test_questions.json`](track-b/test_questions.json) | 화면 정보·기술 용어 검증용 예시 질문셋 (질문·기대 답변 라벨) |

> 본인이 확보한 테스트 데이터를 사용해도 됩니다. 샘플 에셋은 시작점일 뿐, 추가 데이터로 보완하면 더 좋습니다.
